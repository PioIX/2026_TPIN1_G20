# 2026_TPIN1_G20

Integrantes: Martin Rebora y Felipe Nille
Curso: 5to b año informatica



Explicacion del juego:
El juego es una version del clasico juego  higher or lower. En el vos tenes 2 personajes ( jugadores de futbol ) y en base a un dato comun decir quien tiene mas o menos de eso, si no te equivocas avanzas a la siguiente comparacion con el personaje que habias comparado antes (asi hasta perder).
